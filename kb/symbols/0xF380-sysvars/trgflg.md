# trgflg

## Summary
Trigger button and space bar state, updated each interrupt. Bit 0: space bar / trig(0); bit 4: joystick 1 trigger 1; bit 5: joystick 1 trigger 2; bit 6: joystick 2 trigger 1; bit 7: joystick 2 trigger 2. 0 = pressed, 1 = not pressed.
